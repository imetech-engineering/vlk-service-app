# Beveiligingsproblemen melden

Heb je een kwetsbaarheid gevonden in deze app of in de Vlakkelichtkoepel besturing?
Meld het vertrouwelijk via **Security > Report a vulnerability** in deze repository
(privé melding bij GitHub), niet via een openbaar issue.

Vermeld wat je gevonden hebt, hoe het te reproduceren is en welke versie (app en firmware:
tab Update). We bevestigen binnen 5 werkdagen en houden je op de hoogte van de oplossing.
